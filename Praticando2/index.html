Elementos Semânticos

<article>
Representa um conteúdo independente, como uma postagem de blog ou artigo, que pode ser entendido por si só.
Exemplo: https://www.w3schools.com/html/tryit.asp?filename=tryhtml5_article
<header>
Define a área de cabeçalho de uma página ou seção, geralmente contendo títulos, logotipos e menu de navegação.
Exemplo: https://www.w3schools.com/html/tryit.asp?filename=tryhtml5_header
<footer>
Define a área de rodapé da página, geralmente contendo informações adicionais sobre o website, quem fez ou contatos
Exemplo: https://www.w3schools.com/html/tryit.asp?filename=tryhtml5_footer
<nav>
O elemento nav define um conjunto de links de navegação
Exemplo: https://www.w3schools.com/html/tryit.asp?filename=tryhtml5_nav
<aside>
Define alguns conteúdos a parte do principal (como uma barra lateral)
Exemplo: https://www.w3schools.com/html/tryit.asp?filename=tryhtml5_aside
<section>
Define uma seção no documento
Exemplo: https://www.w3schools.com/html/tryit.asp?filename=tryhtml5_section
<details>
Detalhes adicionais que o usuário pode ver ou ocultar
Exemplo: https://www.w3schools.com/tags/tryit.asp?filename=tryhtml5_details
<main>
Conteúdo principal do documento
Exemplo: https://www.w3schools.com/tags/tryit.asp?filename=tryhtml5_main
<summary>
Define um cabeçalho visível para a tag details
Exemplo: https://www.w3schools.com/tags/tryit.asp?filename=tryhtml5_summary
<figcaption>
Define uma legenda para um elemento figure
Exemplo: https://www.w3schools.com/html/tryit.asp?filename=tryhtml_figcaption
<mark>
Define um texto que deve ser marcado ou destacado
Exemplo: https://www.w3schools.com/tags/tryit.asp?filename=tryhtml5_mark
<time>
Define um tempo específico
Exemplo: https://www.w3schools.com/tags/tryit.asp?filename=tryhtml5_time
<figure>
Define um conteúdo independente, como fotos, ilustrações, diagramas etc
Exemplo: https://www.w3schools.com/tags/tryit.asp?filename=tryhtml5_figure
